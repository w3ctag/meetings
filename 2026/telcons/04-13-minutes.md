### Needs for spec changes in response to AI attacks

There might be a need for a "trusted in parallel" primitive, to specify where the browser process checks for properties that a compromised renderer might be lying about.
What other needs are there for spec changes?
After the initial reports are patched, maybe we'll see patterns of spec changes that would have prevented the bugs, and then we can advise that people follow those patterns in the future.
SING should be writing a threat model, but doesn't really have the knowledge. Browser security teams aren't participating there.
